# 🛍️ Customer Shopping Behavior Analysis

An end-to-end data analytics project that analyzes **3,900 customer purchase transactions** to understand shopping patterns, customer segments, product preferences, discount behavior, subscription activity, and revenue contribution.

The project combines **Python, PostgreSQL/SQL, and Power BI** to transform raw transactional data into business-focused insights and an interactive dashboard.

---

## 📌 Project Overview

Understanding how customers purchase, what products they prefer, how discounts affect behavior, and how subscription status relates to spending can help businesses improve customer retention, marketing, and product strategy.

This project focuses on answering these questions through a complete analytics workflow:

**Raw Data → Python Data Cleaning & EDA → Feature Engineering → PostgreSQL → SQL Business Analysis → Power BI Dashboard → Business Recommendations**

---

## 🎯 Objectives

- Analyze customer purchasing and spending patterns.
- Understand customer demographics and purchasing behavior.
- Identify high-performing and highly rated products.
- Analyze discount and promotional behavior.
- Compare subscribers and non-subscribers.
- Segment customers based on purchase history.
- Identify popular products within each category.
- Analyze revenue contribution across age groups.
- Build an interactive Power BI dashboard.
- Translate analytical findings into actionable business recommendations.

| Shopping Behavior | Discount Applied, Promo Code Used, Previous Purchases, Frequency of Purchases |
| Customer Feedback | Review Rating |
| Fulfillment | Shipping Type |

### Data Quality

- **Rows:** 3,900
- **Columns:** 18
- **Missing values:** 37 values in `Review Rating`

## 🧹 Data Preparation & Cleaning

Data preparation was performed using Python and pandas.

### Steps Performed

1. Loaded the transactional dataset using **pandas**.
2. Inspected the dataset structure using `df.info()`.
3. Reviewed descriptive statistics using `df.describe()`.
4. Checked for missing values.
5. Imputed missing `Review Rating` values using the **median rating of each product category**.
6. Standardized column names using **snake_case**.
7. Created an `age_group` feature by binning customer ages.
8. Created a `purchase_frequency_days` feature from purchase-frequency data.
9. Checked the relationship between `discount_applied` and `promo_code_used`.
10. Removed `promo_code_used` after identifying redundancy with the discount field.
11. Loaded the cleaned DataFrame into **PostgreSQL** for SQL-based business analysis.

## 💡 Business Recommendations

Based on the analysis, the project proposes the following business actions:

### 1. Boost Subscriptions
Promote exclusive benefits and incentives for subscribers.

### 2. Strengthen Customer Loyalty
Use loyalty programs to reward repeat buyers and encourage movement into the **Loyal** customer segment.

### 3. Review Discount Strategy
Balance discount-driven sales with margin control, especially for products showing high discount dependence.

### 4. Improve Product Positioning
Highlight highly rated and best-selling products in marketing campaigns.

### 5. Target High-Value Customer Groups
Focus marketing efforts on high-revenue age groups and customers using express shipping.
